# Little Kids Smart Transportation System

<img width="1907" height="907" alt="image" src="https://github.com/user-attachments/assets/981d062a-2e9f-4735-abfd-d4ff15cc624d" />


The system is developed using **PHP** and provides a central platform for managing transportation-related information.

The project focuses on making it easier to manage children, transportation information, and the overall transport process through a simple web application.

#The main objectives of Little Kids are to:

- Improve the organisation of children's transportation.
- Make transportation information easier to manage.
- Reduce manual paperwork and administration.
- Provide a centralised system for storing information.
- Improve communication between people involved in transportation.
- Support safer and more organised transportation of children.

  #What was used

- **PHP** – Backend/server-side development
- **HTML5** – Website structure
- **CSS3** – Website styling
- **JavaScript** – Client-side functionality
- **MySQL** – Database management
- **XAMPP** – Local development environment
- **Git & GitHub** – Version control and project management

## Installation
#1. Install XAMPP

Download and install XAMPP on your computer.

Start:

Apache
MySQL
#2. Clone the Repository

Open your terminal and run:

git clone YOUR_GITHUB_REPOSITORY_LINK

Move the project into:

C:\xampp\htdocs\

For example:

C:\xampp\htdocs\Little-Kids
#3. Create the Database

Open phpMyAdmin through XAMPP.

Create a database for the project.

Example:

little_kids

Import the project's SQL database file if one is provided.

#4. Configure the Database

Update the PHP database configuration with your local MySQL details.

Example:

$host = "localhost";
$username = "root";
$password = "";
$database = "little_kids";

#5. Run the Project

Open your browser and go to:

http://localhost/Little-Kids/

The application should now load
